# Catalog Reference — VoltAgent/awesome-design-md

Source: https://github.com/VoltAgent/awesome-design-md (MIT licensed)

73+ `DESIGN.md` files extracted from real brand sites, organized by category. Folder slugs are lowercase-hyphenated (e.g. `stripe`, `mongo-db`) — confirm the exact slug by browsing the repo tree before fetching, since spelling doesn't always match the display name.

## File contents per brand folder

- `DESIGN.md` — the design system document (visual atmosphere, color palette, typography rules, component styling, layout principles, depth system, responsive behavior, agent prompt guide)
- `preview.html` — visual catalog (colors/type/components), light mode
- `preview-dark.html` — same, dark mode variant
